# Funnel Analysis Project

### Customer Funnel Analysis using Python, Pandas & Plotly

## 📌 Project Overview

This project focuses on analysing customer funnel data to understand customer activity and behaviour across different stages of the funnel.

The objective is to explore customer-related datasets, identify patterns, perform data analysis and create interactive visualisations to support data-driven insights.

## 🎯 Project Objectives

- Analyse customer activity and behaviour.
- Explore customer subscription patterns.
- Examine order-related data.
- Perform data cleaning and preprocessing.
- Identify trends and patterns in the available datasets.
- Create visualisations to present analytical findings.

## 🛠️ Technologies Used

- **Python** – Programming language
- **Pandas** – Data manipulation and analysis
- **Plotly** – Interactive data visualisation
- **Jupyter Notebook** – Development environment

## ⚙️ Installation & Usage

1. Clone this repository:

```bash
git clone https://github.com/pranjaliS213-design/Funnel-Analysis.git
```

2. Install the required libraries:

```bash
pip install pandas plotly jupyter
```

3. Open Jupyter Notebook:

```bash
jupyter notebook
```

4. Open `Funnel_Analysis_project.ipynb` and run the cells.

**Note:** Keep all CSV files in the same project directory as the notebook unless the file paths are updated.
